Moye · Support

Help & frequently asked questions for the Moye Markdown reader.

What is Moye?

Moye is a local-first Markdown reader for long, AI-written documents. It opens straight into a clean preview so you can read like a paper, and edit only when you need to.

How do I open a document?

Use the system file picker to choose a .md file. The app reads it and shows a rendered preview. Double-click to enter edit mode, or press E.

Are my files uploaded anywhere?

No. Moye is offline-first. Files are processed on your device only and never leave it. There is no account, no cloud, and no tracking.

Which formats are supported?

GitHub-flavored Markdown, tables, task lists, math (KaTeX), Mermaid diagrams, syntax-highlighted code, images, footnotes, and nested lists.
